# أوامر سريعة: تحليل الكود

## الاستخدام

### تحليل ملف واحد
```
اقرأ [الملف] وأخبرني بـ:
1. ما يفعله (ملخص في سطرين)
2. أي مشاكل محتملة
3. كيفية تحسينه
```

### تحليل متعدد الملفات
```
اقرأ:
- src/module/file1.py
- src/module/file2.py

قارن بينهما وحدد:
- التشابهات
- الاختلافات
- أي تناقضات
```

## قالب التحليل

```
## تحليل: [اسم الملف]

### الملخص
[ما يفعله الملف في 2-3 سطور]

### المشاكل المحتملة
1. [مشكلة 1]
2. [مشكلة 2]

### تحسينات مقترحة
1. [تحسين 1]
2. [تحسين 2]
```
