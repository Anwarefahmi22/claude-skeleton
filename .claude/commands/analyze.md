# تحليل الكود

## الاستخدام
```
اقرأ [الملف1] [الملف2] [الملف3]
حلّل الكود من حيث:
- الأخطاء المحتملة
- مشاكل الأداء
- مخالفات أمنية
- تحسينات مقترحة

أجب بالعربية مع أمثلة.
```

## أمثلة سريعة

### تحليل ملف واحد
```
اقرأ src/utils/helpers.py
حدد:
1. الدوال التي تحتاج تحسين
2. أي ثغرات أمنية
3. اقتراحات refactoring
```

### تحليل متعدد الملفات
```
اقرأ:
- src/models/user.py
- src/services/user_service.py
- tests/test_user.py

أقترح أفضل طريقة لإعادة هيكلتهم لتحسين الصيانة
```
