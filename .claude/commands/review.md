# أوامر سريعة: مراجعة الكود

## الاستخدام

```
راجع [الملف/المجلد] مع التركيز على:
- الجودة العامة
- الأداء
- الأمان
- قابلية الاختبار

أجب في تنسيق واضح.
```

## قالب المراجعة

```
## مراجعة: [الملف]

### ✅ ما يعمل جيداً
- [نقطة إيجابية 1]
- [نقطة إيجابية 2]

### ⚠️ يحتاج تحسين
- [نقطة للتحسين 1]
- [نقطة للتحسين 2]

### 🔧 اقتراحات محددة
1. [اقتراح 1] - [السبب]
2. [اقتراح 2] - [السبب]

### 📊 التقييم
- الجودة: ⭐⭐⭐⭐☆
- الأداء: ⭐⭐⭐⭐☆
- الأمان: ⭐⭐⭐⭐☆
```
