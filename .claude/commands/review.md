# مراجعة الكود

## الاستخدام
```
راجع [الملف/المجلد] مع التركيز على:
- [الجودة العامة]
- [الأداء]
- [الأمان]
- [قابلية الاختبار]

التزم بـ:
- معايير الكود في CLAUDE.md
- أنماط التصميم في .claude/context/patterns.md

أجب بتنسيق:
## ✅ ما يعمل جيداً
## ⚠️ يحتاج تحسين
## 🔧 اقتراحات محددة
## 📊 ملخص
```
