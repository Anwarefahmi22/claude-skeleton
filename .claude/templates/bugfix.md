# قالب: إصلاح خطأ

## قبل الطلب

1. حدد الملف/الدالة التي يحدث فيها الخطأ
2. اجمع رسالة الخطأ الكاملة
3. حدد خطوات إعادة إنتاج المشكلة

## القالب

```
أصلح خطأ: [عنوان مختصر]

## معلومات الخطأ
- **الملف**: [path/to/file.py]
- **السطر**: [رقم السطر] (إن وُجد)
- **رسالة الخطأ**: 
  ```
  [نسخ رسالة الخطأ]
  ```
- **نوع الخطأ**: [TypeError/ValueError/NullPointer/...]

## خطوات إعادة إنتاج المشكلة
1. [الخطوة 1]
2. [الخطوة 2]
3. [الخطوة 3]

## السياق
- الوظيفة المتوقعة: [ما يجب أن يحدث]
- ما يحدث حالياً: [ما يحدث خاطئاً]
- البيئة: [Python 3.11 / Node 18 / ...]

## معلومات إضافية
- المستخدم يتأثر: [وصف من يتأثر]
- تكرار المشكلة: [كل مرة / أحياناً / نادراً]

## القيود
- لا تغير الواجهة/الـ API
- حافظ على التوافق مع الإصدارات السابقة
- أضف اختبارات لمنع regress
```

## مثال

```
أصلح خطأ: خطأ في تسجيل الدخول عند البريد الإلكتروني بحروف كبيرة

## معلومات الخطأ
- **الملف**: src/auth/login.py
- **السطر**: 45
- **رسالة الخطأ**: 
  ```
  AttributeError: 'NoneType' object has no attribute 'id'
  ```

## خطوات إعادة إنتاج المشكلة
1. افتح صفحة تسجيل الدخول
2. أدخل email@example.COM (بحروف كبيرة)
3. اضغط تسجيل الدخول
4. ❌ خطأ يحدث

## السياق
- الوظيفة المتوقعة: تسجيل الدخول ناجح
- ما يحدث حالياً: crash عند التحقق
- البيئة: Python 3.11, Django 4.2

## معلومات إضافية
- المستخدم يتأثر: أي مستخدم يدخل بريداً بحروف كبيرة
- تكرار المشكلة: كل مرة
```
