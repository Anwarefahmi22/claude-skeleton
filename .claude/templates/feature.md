# قالب: إضافة ميزة جديدة

## قبل الطلب

1. حدد مكان الميزة في المشروع
2. افهم العلاقات مع المكونات الأخرى
3. جهّز أمثلة على المدخلات والمخرجات المتوقعة

## القالب

```
أضف ميزة: [اسم الميزة]

## الوصف
[وصف سريع للمشكلة/الاحتياج]

## الموقع
- الملف: [src/path/feature.py]
- الدالة/الفئة: [Name]

## المتطلبات
- [متطلب 1]
- [متطلب 2]

## السلوك المتوقع
- المدخلات: [وصف]
- المخرجات: [وصف]
- الحالات: [حالة1], [حالة2]

## القيود التقنية
- اللغة: [Python/JavaScript/...]
- الإطار: [Django/React/...]
- نمط التصميم: [اتبع existing pattern]

## الاختبارات
- ما الذي يجب اختباره؟
- ما الحالات الخاصة؟

## مرجع
- 文件 مشابهة: [existing-file.py] (للاتباع)
```

## مثال

```
أضف ميزة: تصفيه المنتجات حسب السعر

## الوصف
تمكين المستخدم من تصفيه قائمة المنتجات حسب نطاق سعري

## الموقع
- الملف: src/products/filter.py
- الدالة: filter_by_price

## المتطلبات
1. قبول قائمة منتجات وكلفين (min, max)
2. إرجاع المنتجات في النطاق فقط
3. دعم أسعار null

## السلوك المتوقع
- filter_by_price(products, 10, 50) → المنتجات priced $10-$50
- filter_by_price(products, null, 50) → المنتجات ≤ $50
- filter_by_price([], 10, 50) → []

## مرجع
- اتبع النمط المستخدم في sort.py
```
