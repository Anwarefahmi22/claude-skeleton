# قالب: إعادة هيكلة

## الاستخدام

```
أعد هيكلة: [ما الذي ستُعاد هيكلته]

## الهدف
- [ ] تحسين القراءة
- [ ] تقليل التكرار
- [ ] تطبيق نمط تصميم

## الكود الحالي
الملف: [path/to/file]

```[language]
[الكود الحالي]
```

## المشاكل المحددة
1. [مشكلة 1]
2. [مشكلة 2]

## القيود
- حافظ على الوظيفة الحالية
- لا تغير الواجهة/الـ API
```

## مثال

```
أعد هيكلة: validate_user_data function

## الهدف
- [x] تحسين القراءة
- [x] تقليل التكرار

## الكود الحالي
الملف: src/validators/user.py

```python
def validate_user_data(data):
    errors = []
    if 'name' not in data:
        errors.append("Name required")
    # ... أكثر من 50 سطر من validation
    return errors
```

## المشاكل المحددة
1. دالة طويلة جداً
2. منطق مكرر

## القيود
- حافظ على نفس الـ API
- نفس رسائل الخطأ
```
