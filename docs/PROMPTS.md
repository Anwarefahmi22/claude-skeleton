## تحليل الكود

### تحليل سريع

```
اقرأ [الملف] وأخبرني بـ:
1. ما يفعله
2. أي مشاكل محتملة
3. كيفية تحسينه
```

### تحليل مع مقارنة

```
اقرأ [الملف1] و [الملف2]
قارن بينهما وحدد:
- التشابهات
- الاختلافات
- أي تناقضات
```

## مراجعة الكود

### مراجعة شاملة

```
راجع [الملف/المجلد] مع التركيز على:
- الجودة العامة
- الأداء
- الأمان
- قابلية الاختبار

أجب بتنسيق واضح مع أمثلة.
```

### مراجعة Security

```
راجع [الملف] من ناحية الأمان:
- حقن SQL / XSS / CSRF
- إدارة الجلسات
- تشفير البيانات
- الصلاحيات

اقترح إصلاحات إن وُجدت.
```

## كتابة الاختبارات

### اختبار دالة

```
اكتب اختبارات لـ [الدالة] تشمل:
- الاختبار العادي
- الحالات الحدية
- معالجة الأخطاء

استخدم [pytest/jest/...]
```

### اختبار API

```
اكتب اختبارات لـ endpoint: [GET/POST] /api/[endpoint]

اختبر:
- النجاح
- البيانات الخاطئة
- الصلاحيات
- الأداء
```

## إصلاح الأخطاء

### تشخيص سريع

```
الخطأ في [الملف:السطر]:
[رسالة الخطأ]

ما هو السبب المحتمل؟
ما الحل؟
```

### إصلاح معوق

```
هذا الخطأ يحدث في [البيئة]:
[الخطأ]

الخطوات: [1, 2, 3]

لا أستطيع إصلاحه بـ [ما جربته]
ما الخيارات الأخرى؟
```

---

## 💡 نصائح

1. **كن محدداً**: "الدالة X في الملف Y" أفضل من "الكود"
2. **أدخل السياق**: ما الذي تحاول تحقيقه؟
3. **حدد القيود**: الوقت، اللغة، النمط المطلوب
4. **اطلب تنسيق محدد**: "أجب في جدول" أو "اكتب كـ Python code block"
