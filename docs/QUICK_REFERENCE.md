# 🚀 مرجع سريع

## أوامر سريعة

### قراءة الملفات

```
اقرأ ملف
اقرأ ملف1 ملف2
اقرأ src/*.py
```

### تنفيذ أوامر

```
نفّذ: npm run build
نفّذ: python test.py
نفّذ وعرض النتيجة: ls -la
```

### البحث

```
ابحث في: src/**/*.py
ابحث عن: functionName
```

---

## صيغ Prompt السريعة

### شرح

```
اشرح [concept] ببساطة
اشرح الفرق بين [A] و [B]
```

### اقتراحات

```
اقترح تحسينات لـ [الملف]
اقترح بدائل لـ [library]
```

### مقارنة

```
قارن [option1] vs [option2] for [use case]
```

## رموز مفيدة

| الرمز | المعنى |
|-------|--------|
| `عربي` | بالعربية |
| `English` | بالإنجليزية |
| `**bold**` | أهمية |
| `> quote` | اقتباس/مثال |
| `code` | كود |

---

## نصائح ذهبية

1. ابدأ بـ "اقرأ الملف" بدلاً من نسخ ولصق
2. استخدم المسارات النسبية من جذر المشروع
3. حدد الإصدار إن كان مهماً: "Python 3.11"
4. اطلب "باختصار" أو "في نقطتين" لتقليل الرد
